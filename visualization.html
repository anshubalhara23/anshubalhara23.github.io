OlistEcom — 17-Question Business Dashboard

A 6-page, 28-visual Power BI dashboard built on top of the OlistEcom data warehouse, designed to answer 17 real business questions about orders, revenue, customers, and sellers on a Brazilian e-commerce marketplace.

Power BI DAX Data Modeling Star Schema

The dashboard sits on top of the Gold-layer star schema from the OlistEcom warehouse (4 dimensions, 3 fact tables) and spans 6 pages covering an executive summary along with deeper cuts by customer, revenue, state, and seller performance. In total it answers 17 distinct business questions across 28 visuals.

Because the source data had multiple fact tables joined on order_id, Power BI's auto-detected relationships initially created conflicting fact-to-fact links — these were manually deleted and a dimension-to-dimension relationship cycle was resolved so the model would calculate correctly.

Date relationships were built using DATEVALUE() calculated columns rather than relying on auto date/time. All DAX measures are organized in a dedicated _Measures table to keep the model clean and easy to navigate. The date dimension itself is generated inside Power BI using DAX's CALENDAR() function rather than being loaded from the warehouse.
